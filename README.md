# Personal Financial Information Organizer

## Overview

This project is a spreadsheet template developed with LibreOffice Calc to organize personal information and financial records in a structured format.

It provides separate sections for personal identification details, bank income statements, and monthly income records, helping users centralize relevant information for financial organization and documentation.

## Features

- **Personal Information:** Fields for the account holder's name, CPF, date of birth, address, telephone numbers, email, and related information.
- **Bank Income Statements:** Sections to record financial information from different banks and organize current reported balances.
- **Bank Selection:** A predefined list of banks to support consistent data entry.
- **Monthly Income Records:** A structured area for recording dates, income categories, and values.
- **Supporting Documents:** Fields for organizing references to supporting documents, such as bank statements and payslips.
- **Multi-Sheet Organization:** Separate worksheets for personal details, bank information, and financial records.

## Tools and Technologies

- **LibreOffice Calc**
- Spreadsheet design and data organization
- Structured financial recordkeeping

## How to Use

1. Download the `.ods` file from this repository.
2. Open it with LibreOffice Calc.
3. Enter the relevant information in the appropriate worksheet.
4. Complete the bank information and financial record sections as needed.
5. Review the information to help keep records organized and up to date.

## Project Purpose

The purpose of this project is to demonstrate how spreadsheets can be used to structure personal and financial information in a practical, organized, and accessible format.

This project is part of my learning portfolio and reflects my interest in spreadsheet development, data organization, and practical administrative solutions.

## Privacy and Data Protection

This template includes fields for personal identification and financial information. Use fictional or anonymized data when sharing examples publicly. Do not upload real CPF numbers, contact details, bank statements, payslips, or other confidential financial records to a public repository.
